# 07 — 首版系统的实施依赖与交付

完整首版由 A–F 共同构成，核心发布条件为 G0–G6。工作包定义系统交付责任；实际开发任务采用根[开发入口](../AGENTS.md)的模板。

## 依赖与共同输入

~~~mermaid
flowchart LR
  A[A 领域与契约] --> B[B 事件与恢复]
  B --> C[C 感知与认知]
  B --> D[D 记忆与学习]
  C --> E[E 能力与表达]
  D --> E
  E --> F[F 整体验收]
~~~

共同输入为愿景、I01–I15、领域与行为规范、core/extension 1.0 草案、配置、技术清单及场景评测设计。逻辑模块在单体内协作，各包可细分迭代，基础贯通不等于首版交付完成。

## A — 领域与首版契约

确定完整能力的领域所有者、依赖方向、状态转换和验收归属。交付统一模型、Rust/TS DTO 与 Schema 映射、威胁模型、初始化设计及评测预算；有实际消费者时再定义 Protobuf 映射。工程依赖解析产生真实锁文件。

验收覆盖契约正反例、框架依赖隔离、能力—状态—场景追踪和安全评审。身份、人格、认证主体和描述对象保持独立；不为不存在的旧系统建立转换层。

人格认知机制的输入为研究材料、既有 Appraisal/承诺与状态规范；交付 NeedDefinition/NeedState 的规则与生命周期，以及 MotivationCandidate 依据快照、关切归并和历史依据/执行前提的区分。A 固定定义发布与人格采用的边界，防止重复调度或规则升级绕过确认；交 B/C 实现。本阶段不新增公开 HTTP 或 wire payload，后续真实消费者需要时再定义并注册准确业务契约。

## B — 事件、状态与恢复

依赖 A 的模型、契约和数据政策。交付 StateStore、事件/快照、inbox/outbox、分支、读集、任务检查点、删除屏障和 WebUI 事件桥；从空库建立复合归属、约束和隔离。

验收覆盖事务失败、并发写入、重复事件、幂等、FK/RLS、备份恢复、撤权/删除竞争及分支一致性。事件、状态版本与 outbox 原子提交，回放不重复外部效果，设备和会话不替代持续身份。

需要状态的输入是 A 的定义及来源链；保存确切版本、贡献/关联、有效时间与删除依赖，协调评价/需要更新、失效屏障和幂等交接。验证同一关切并发创建、接收后崩溃、重算延迟、来源修订、人格编辑、分支与离线恢复；交给 C/D 的投影不能补算停机经历。

## C — 感知、认知与选择

依赖 B 的合法状态、感知来源和能力快照。交付 ContextCompiler、模型路由、SelfModel、Belief/WorldModel、情境评价、互动机会、注意/承诺仲裁和过期重算；可选择交流、等待、沉默或自主活动。

验收区分可见输入与评测真值，覆盖 ACL、TTL、read_set、反事实、模型替换和未知类型拒绝。外部内容保持 DATA，模型输出候选，事实和动作经验证提交；缺失感知、人格和关系不能被用来编造经历或扩大权限。

补齐人格影响注意/解释/核验/候选/权衡的语义，按旧需要评价、验证变化，再把动机依据交给现有决定/机会/目标。验证空集启动、普通任务直达、多需要竞争、容量与同源自证；事件和有界时间沿现有调度运行，未校准时仅检查有效性/期限。拒绝后不重复请求，需要可未满足、放弃或不行动；交给 E 的仍是合法决定。

## D — 记忆、关系与学习

依赖 B 的历史和来源链，与 C 的评价和决定相接。交付分层记忆、混合检索、证据冲突/撤回、共同理解、局部边界与修复、叙事投影，以及有证据、可回滚的人格/偏好/技能更新。

验收覆盖跨时共同活动、证据独立性、纠错、偏好修订、删除级联、保留集和消融。学习由各聚合所有者合法提交；单次反馈、固定好感度或模型感想不能代替关系与行为变化，删除后不能通过反思重建内容。

反馈按对象分流到 Belief、人物×领域的关系可靠性、程序性记忆/Habit 或 PersonaChangeProposal；学习提议由各领域所有者验证，再由应用提交。单次纠错不得跳到人格重写；跨领域信任、重复同源证据和必要确认是回归重点。向 C 提供有来源的局部变化，不建立第二份需要权威。

## E — 开放能力、行动与表达

依赖 A–D、扩展协议、输出端点和媒体规范。交付完整插件宿主、契约注册、依赖解析、绑定、隔离、流控、停止/清理，受限任务与控制权，增量表达和真实送达；提供 fake audio/visual/avatar/game/device、React 网页与受控桌面桥。

界面交付顺序为：A/B 的页面—能力/API 对照 → 导航及通用组件 → 正式 `/chat` 与扩展管理 → 配置、模型、交互实例与依赖 → `/console` 沙盒、日志与 Trace → 身份、人格、记忆、关系、任务和审批。接口与交互验收以[控制台规范](design/UIUX/design/UX_SPEC.md)为准，Tauri 共享同一应用边界。

验收覆盖匿名未知业务、依赖晚到/循环、注册回滚、迟到代次、流控/取消/撤权、隔离失败、控制接管和跨媒介契约。发现、绑定或租约不代替动作授权；子执行器不成为身份副本。真实媒体逐项接续观察—动作—结果与实际时序验收。

表达与行动只消费已验证决定及允许的状态投影；不从需要强度直接执行。任务区分历史动机与持续前提，反馈关联实际结果并验证缓解条件。控制台分开呈现当前关切、长期偏好和任务，所有管理命令经服务端校验；验证私密需要不经动机、自述或诊断流出，后续媒介结果交 F 实测。

## F — 整体质量与发布验收

依赖 A–E 的实现、回执和证据。交付真实文字 WebUI E2E、多人/多会话、模型替换、fork、跨设备交接、故障恢复、安全回归、成本和长期自然度评估，以及部署/恢复手册。

验收执行 G0–G6、属性/差分/故障测试、数据库初始化与恢复、浏览器与桌面平台测试、长期行为保留集及盲评。控制台覆盖移动端、空/错/载状态、无障碍、视觉回归和构建验证。机制正确性与模型表现分别计量，可比实验控制模型、输入和预算。

人格/需要分别干预，补充十类情境 N01–N10、Q09、V13–V15、A09/A10 与 H07。多次运行、保留集与机制消融分别评估一致性、适应性、帮助、打扰和成本；审计理由本身不能证明因果作用。当前只交付验证设计，运行验收责任仍在后续 A–F 工程阶段。

## 能力验收与资源预算

交互与工具扩展沿以下责任衔接；本轮交付设计、契约、配置及检查，运行实现仍属后续工程：

第三方角色客户端复核进一步要求：A 校验 required_features/connection_dependents 的结构与归属以及面板应用操作白名单；B 保存连接和映射修订、唯一输出关联；C/D 不把外部 AI/回显/整份历史当新用户经历；E 根据客户端实际协议实现主动或反向适配、可选能力降级与单一呈现路径；F 执行 bridge_* 场景，验证不同协议、受限接口、模型切换、反馈循环和共享连接撤销。增加的兼容矩阵/外部协议版本、动作资源映射和端到端测试成本单独计量；合成 C7 样例不是实际平台支持证明。

| 工作包 / purpose | inputs 与 expected changes | domain invariants / failure cases / tests | cost 与 handoff |
|---|---|---|---|
| A：明确扩展职责与接口 | 扩展/媒介/UI 规范；连接定义、实例、配置会话及交互服务草案；工具独立样例 | 共用宿主不强制共用交互协议；核验正反例、服务/资源摘要、核心结构复用；未知语义不得仅靠注册生效 | 契约验证与维护成本；交 B/E 准确版本 |
| B：配置与实例持久化 | A 的归属和版本；配置/凭据引用、操作关联、绑定失效、恢复屏障 | 同契约多提供者；多账号隔离；保存/连接/交付分开；验证崩溃、迟到认证、撤权、删除与恢复 | 状态/挑战保留、幂等记录；交 E 合法投影 |
| C/D：共享认知与历史 | 合法 Observation/Outcome、实例来源映射；复用既有认知、需要与学习 | 平台不另存人格或记忆权威；修订/撤回传播，不自报可信 actor；验证换平台及多人隔离 | 来源编译/推理预算沿原机制；交 E 合法决定 |
| E：接入与配置体验 | A/B 契约与实例；实现宿主内 WebChat、声明表单、配置会话和隔离面板；工具独立调用 | 核心/UI 无平台枚举；绑定无就绪循环；关闭面板不停止服务端连接；专用面板不绕过管理授权 | 实例并发、连接重试/探测、认证 TTL、流量和面板资源有界；交 F 真实回执 |
| F：跨路径验收 | WebChat、匿名 A/B、独立浏览器工具和组合贡献 | 执行 connector_*、tool_*、webchat_*；核验两实例、配置错误、升级/停用/断线、客户端离线、命令快路与真实交付；静态样例不证明运行 | 浏览器/宿主故障与安全测试成本另计；返回证据及未测项 |


每项能力关联责任工作包、实现状态、真实或模拟、证据及剩余交付责任。核心验收完成后，真实语音、视觉、形象、游戏、多端及新形态继续沿 E/F 交付。

预算覆盖依赖解析、数据库与事件保留、模型 token/延迟/费用、检索与反思频率、并发/带宽/算力及评测资源。记录实际使用与不确定性，未测项目保持未测。任何质量分都不能抵消越权、已删内容复活或未送达冒充已表达。

动态需要另计规则检查 CPU、活跃状态/来源边容量及保留、重算/交接、调度与模型调用、独立反馈和长期对照成本。没有实测成本或校准阈值时保持未测；不为动机快照新增调度基础设施，不以逐 tick 模型调用实现自主性。
