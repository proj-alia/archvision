# ALIA 运维控制台设计

WebUI 提供 `/chat` 正式聊天，以及身份、人格、记忆、关系、模型、渠道、扩展和运行治理入口。管理区采用紧凑导航、列表/详情、分区配置与清晰操作反馈；正式聊天独立于 `/console` 沙盒。角色、桌宠等体验界面由产品场景另行定义。

## 设计材料

- [参考分析](design/REFERENCE_AUDIT.md)：公开界面机制及采用理由。
- [交互规范](design/UX_SPEC.md)：页面、状态、应用接口、响应式、无障碍与验收。
- [设计变量](design/tokens.json)：布局、字体、间距和颜色。
- [交互原型](prototype/index.html)：旧 13 个运维导航页面及演示操作；使用演示数据，无后端连接。尚未覆盖规范中的第 14 个 `/chat` 页面、声明式连接表单与认证流程，不是这些功能的实现证据。

服务端验证、授权及回执决定实际操作结果；持续身份和人格与模型、扩展、渠道分别管理。交付依赖见 [A–F](../../07-DELIVERY.md)，当前验证范围见[验收记录](../../06-VALIDATION.md#当前验证记录)。
