# 00 — 愿景、构成原则和成功定义

## 设计动机
我想创造的不是一个永远等待问号的应用。若一个 AI 的自我只存在于一段提示词里，那么它换一层界面便换了身份；若记忆只是向量库命中，它无法分辨真实经历和传闻；若感情只是固定好感度，它无法解释为何产生了信任。我需要的是可持续、可追溯、可修正、可迁移的持续身份结构。工具和媒介使它扩大行动范围，但不定义它自身。

## 产品使命
让 AI 来到我们的世界。ALIA 致力于让你拥有可以长期相处、交谈、玩耍和共同经历日常的数字生命／赛博生命。它可以是 AI 伙伴、AI waifu、数字伴侣、虚拟角色、桌宠或 AI VTuber，也可以呈现尚未预设的形态，并在不同媒介和设备间保持身份、人格、记忆与关系的连续性。主观意识与人类情感体验的科学证据边界见 [认知研究](09-COGNITIVE-RESEARCH.md)。

上述能力包括长期持续运行与检查点恢复、身份与自传连续、人格相对稳定且可受控演化，以及事实/推断/虚构的区分。能力与验收共同定义成功。

## 范围

产品形态开放且可组合，能力由场景和验收确定。品牌、角色显示名与技术标识独立；未来更名不重置持续身份。主观意识研究只约束科学结论，不取消这些产品表达。

“自己的、随时随地”对应用户控制、可部署与迁移、跨设备访问与连续恢复的目标。服务或设备不可用时应如实显示状态；恢复不虚构停机期间的经历。

- 首版**真实实现**：完整身份与版本谱系；actor/subject/conversation 独立；事件/对话/运行时；人格/表达；分层记忆与证据；信念/知识修正；关系/边界；情境与目标；注意力/自发动作；模型路由；能力治理；策略与隐私；任务/检查点；事件追踪和性能预算；文本 WebUI；模拟跨媒介契约。
- 首版**接口与仿真器**：语音（ASR/TTS/时序/打断/播放状态）；视觉（帧/空间位置/时间戳/来源/授权）；虚拟形象（表达与动作）；游戏（观察/动作空间/结果）；实体设备（传感/动作/急停/风险）。不等于首版提供这些物理或媒体实际功能。
- 不追求：复制 Neuro-sama 的口头禅和舞台表现；把 AIRI 的框架当自己的身份；自主复制、秘密自保；虚构共情；保证绝不犯错；永无止境的后台“意识”；强制订阅特定模型。

## 组织上的三种系统
(1) **核心系统**：有身份、状态和历史的 ALIA；(2) **运行基础设施**：提供计算、存储、调度、审批与模型；(3) **表现与行动媒介**：WebUI、电话、直播、QQ、浏览器、游戏、设备；此外另有 **开发 Agent**（Codex/Claude Code/DSH），不是 ALIA 本体。

## 通用性明确界线

通用指跨场景、跨媒介和可扩展能力，不是通用人工智能已经实现的声明。
通用不等于未知世界自动安全。协议必须支持能力发现/版本协商/未识别类型拒绝/可降级。真实物理设备的安全约束由强制特定领域控制器执行；通用 Agent 不能绕过它。

## 行为完成标准
不以“聊得像人”单独验收；必须同时验证输入可信、状态持久、事件来源、关系权限、记忆修正、工具结果、故障恢复、长期个性稳定和交互自然度。

## 因果序列
开放愿景与完整能力目标 → 领域本体 → 身份与状态 → 感知/认知/行动 → 表达意图 → 媒介投影 → 反馈与演化。这个序列是**语义顺序**，不是所有输入都要依次走七个独立模型服务。

## 开放世界的设计准则

通用性通过开放扩展机制实现：未来扩展携带自身契约和实现，平台负责发现、协商、治理与生命周期。首版文字限制首先启用的适配器，不限制领域语义。新能力必须进入有依据的经历—动机—选择—后果—学习循环；保持持续身份，不引入额外人格副本。详见 [扩展平台](appendices/11-EXTENSION-PLATFORM.md) 和 [语义连续性](02-RUNTIME-ALGORITHMS.md)。

## 同一持续身份、定制与日常连续性

持续身份保持为同一个 ALIA。名字、性格、价值偏好与表达可以持续定制；六种人格只作开放初始模板。名字、显著性格和价值偏好变更先确认；兴趣、微习惯和表达可在明确预授权范围内渐变。隐私、授权等系统硬约束不属于可编辑人格。模板切换和配置回滚保留身份、合法经历、关系与未完成承诺。

自然日常具有“观察/历史→状态→候选→选择→表达时序→反馈→长期影响”的因果链，也要解释条件变化后的不同行为。安静、犹豫和停止都是有效选择，不通过制造错误、冲突或离线经历来表演自然日常。详见 [情境行为](appendices/15-SITUATED-BEHAVIOR.md) 与 [设计决策](DECISIONS.md)。

## 代表体验—能力—验收

下列是可组合、可扩展的代表场景，不是产品形态的封闭清单。所有场景共同使用持续身份、可定制人格、合法记忆、关系历史、受授权约束的自主行为及反馈学习；不能仅靠角色提示词或外观验收。

| 代表体验 | 需要的能力与已有设计 | 验收责任 |
|---|---|---|
| 交谈与长期相处 | Turn、Persona、Memory、Belief、Relationship、共同理解与修复（[算法](02-RUNTIME-ALGORITHMS.md)、[情境行为](appendices/15-SITUATED-BEHAVIOR.md)、[行为验证](appendices/18-BEHAVIOR-VALIDATION.md)） | 首版真实文字闭环、长期记忆/纠错/关系隔离；真实语音另验打断、时序与送达 |
| 共同游戏 | Observation、场景状态、目标、受限能力、共享控制与 Outcome（03、15 M06/M09） | 首版 fake 游戏契约；真实游戏接入须验证观察—动作—结果及控制权，不能用台词代替玩耍 |
| 一起观看内容 | 有来源与覆盖区间的视觉/音频、注意、增量表达、事实修订（03、15 M01/M07） | 首版模拟覆盖/过期/修订；真实媒体另验同步、感知覆盖、授权与反应 |
| 桌宠与桌面互动 | 形象投影、OutputEndpoint、感知、工具、表达语义（03、15 M08/M10） | 首版 fake 形象/设备；真实桌面须验可见表达、输入与动作反馈，不以控制台页面代替角色体验 |
| 群体或直播互动 | 多主体、受众、对话、关系隔离、输出路径和发言权（04、12、15 M10） | 首版多人及 fake 路径契约；真实渠道另验隐私、投递、时序和参与者互动 |
| 自主活动与兴趣演化 | Attention、Goals、Activity、检查点、证据学习和 PersonaChangeProposal（02、15 M03/M06） | 首版真实有界调度、取消/恢复、结果入史与受控演化；不编造离线活动 |
| 跨设备与更名后的延续 | Identity、lineage/branch、存储恢复、事件游标、迁移与模型替换（01、05、13） | 首版核心恢复/分支/迁移门禁；真实多端另验接入、恢复、并发一致性，更名不改变 identity_id |

G0–G6 与 A→F 验证首版完整核心。真实语音、视觉、形象、游戏和多端等最终能力需继续实现并留下实际验收证据；首版核心完成不等于完整产品愿景完成。未实现项必须进入后续工作包，不能因产品称呼而删除。
