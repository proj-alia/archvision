## 读法与证据边界

结论等级沿用 [情境行为](15-SITUATED-BEHAVIOR.md)：R 为既有项目/用户要求，E 为外部研究，D 为架构推导，H 为待实验假设。本矩阵的机制解释均为 D，受 R 的身份、证据、授权、删除和恢复约束；“能产生类似自然效果”仍为 H。外部研究只支持机制选择，不能替代这些场景的实测。

每行沿“输入/历史 → 状态 → 候选与选择 → 表达时机 → 反馈/长期影响”追踪。输入指**需要获得的合法证据**，不表示原文真的附带媒体。没有证据的历史保持未知，不从作者旁白灌入系统。

覆盖记号：B1＝[02 认知/注意/自主](../02-RUNTIME-ALGORITHMS.md)，B2＝[03 媒介/表达](../03-MEDIA-EXPRESSION.md)，B3＝[12 评价/承诺/共同理解/送达](../02-RUNTIME-ALGORITHMS.md)，B4＝[04 权限/删除](../04-SECURITY-DATA.md)，B5＝[05 状态](../05-STATE-CONTRACTS.md)与[13 恢复/约束](13-DATA-STORAGE.md)。这些是**设计职责而非已实现能力**。“缺口”标识场景所需的机制连接和条件，完整职责见情境行为规范的 M01–M10。

判定：**可保留**＝互动意图可转行为规范；**需证据**＝文字描述、推测或旁白不足；**改写边界**＝文学越权/不可靠行为改作拒绝、授权或虚构场景。即使“可保留”，也不意味着媒体能力已具备。原台词、情绪读心、停顿秒数都不是验收答案。

## 场景与验证的对应关系

八条贯通时序、机制消融与保留集见[行为验证与时序](18-BEHAVIOR-VALIDATION.md)。所有“需证据”条目在后续夹具中必须选择：提供真实媒体，提供清楚标注且不含答案的模拟观测，或保留信息缺失并以克制/澄清为正确约束。不得通过加入旁白答案把感知问题变成抄答案。

71 个场景的主要职责都能容纳于既有领域。新增设计对象是对已有状态的结构化细化，尚无证据支持为每种自然效果新建一个独立服务、人格或专用模型。模型是否能把这些状态转成合宜语言，仍须与机制正确性分开实测。
