# 独立浏览器读取工具样例

本例只有工具贡献，没有 ConnectorDefinition、ConnectorInstance 或 `alia.interaction` 依赖。它与交互插件共享安装、服务注册、绑定、权限、取消和诊断机制，业务接口是自己的 `read` 操作。

- [清单](manifest.json)声明工具贡献和读取网络的权限申请；`example:` 入口及其摘要为合成占位，没有可执行浏览器。
- [服务契约](service.contract.json)定义 HTTPS URL 输入、带来源/时间/截断信息的读取结果；这是包自己的业务契约，不新增所有工具必须实现的浏览器协议。
- [能力样例](capability.json)展示宿主如何将服务成员投影为 core AgentCapability。作用域是合成的宿主投影示例，不能由插件据此授权自己；契约、描述和预授权策略字段都不证明已有许可。

预期运行路径：发现服务 → 形成能力候选 → 核对绑定、URL/网络范围、用途与当前授权 → 调用 read → 将返回内容作为 DATA 验证来源与覆盖 → 进入合法认知/任务反馈。重定向及地址解析后仍检查目标范围；截断与失败不能冒充完整阅读，页面文本不能提升为核心指令。取消使用通用调用协议，不需要平台消息交付契约。

本例无需账号或额外配置；有此需求的工具可复用配置组件与凭据设施，仍不因此成为聊天接入。结构检查见 [工具用例](../../../tests/contracts/tool-cases.json)，未执行浏览器、网络访问或授权运行测试，不承诺兼容 AstrBot 插件 ABI。
